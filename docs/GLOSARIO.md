# Glosario

Cada concepto con su nombre en pantalla y en el código. Usar siempre estos términos.

| En pantalla                                                         | En el código                                                 | Notas                                                                             |
| ------------------------------------------------------------------- | ------------------------------------------------------------ | --------------------------------------------------------------------------------- |
| Movimiento                                                          | `transaction`                                                |                                                                                   |
| Ingreso / Egreso / Transferencia interna                            | `income` / `expense` / `transfer`                            | `TransactionType`. Mandar plata a otra persona, aunque sea por transferencia bancaria, es un egreso |
| Monto                                                               | `amountCents`                                                | Entero en centavos                                                                |
| Moneda                                                              | `currency`                                                   | `ARS`, `USD`                                                                      |
| Monto original                                                      | `original`                                                   | Lo que decía un comprobante en otra moneda: `amountCents`, `currency`, `rate`     |
| Fecha                                                               | `date`                                                       | Día del consumo o ingreso                                                         |
| Fecha de pago                                                       | `paymentDate`                                                | Base del balance mensual                                                          |
| Cuenta                                                              | `account`                                                    |                                                                                   |
| Cuenta destino                                                      | `toAccountId`                                                | Solo transferencias                                                               |
| Monto destino                                                       | `toAmountCents`                                              | Solo entre monedas distintas                                                      |
| Efectivo / Cuenta bancaria / Billetera virtual / Tarjeta de crédito | `cash` / `bank` / `wallet` / `credit_card`                   | `AccountType`                                                                     |
| Categoría                                                           | `category`                                                   |                                                                                   |
| Categoría padre                                                     | `parentId`                                                   |                                                                                   |
| Nivel                                                               | `depth`                                                      | 1 a 3; se calcula, no se guarda                                                   |
| Tipo de categoría                                                   | `kind`                                                       | `income` o `expense`                                                              |
| Etiqueta                                                            | `tag`                                                        |                                                                                   |
| División                                                            | (se eliminó)                                                 | Ahora es un renglón con su propia categoría                                       |
| Ítem                                                                | `item`                                                       | Renglón de un ticket                                                              |
| Producto                                                            | `item`                                                       | En pantalla, los ítems de un ticket se llaman productos                           |
| Descripción                                                         | `description`                                                |                                                                                   |
| Nota                                                                | `note`                                                       |                                                                                   |
| Borrador / Confirmado / Proyectado                                  | `draft` / `confirmed` / `projected`                          | `TransactionStatus`                                                               |
| Origen                                                              | `source`                                                     | `manual`, `document`, `import`, `installment`                                     |
| Editado                                                             | `edited`                                                     |                                                                                   |
| Papelera                                                            | `deletedAt`                                                  |                                                                                   |
| Archivada                                                           | `archived`                                                   |                                                                                   |
| Documento                                                           | `document`                                                   | Archivo subido                                                                    |
| Ticket / Captura / Resumen de tarjeta                               | `receipt` / `screenshot` / `card_statement`                  | `DocumentKind`                                                                    |
| Procesando / Listo / Confirmado / Descartado / Error                | `processing` / `ready` / `confirmed` / `discarded` / `error` | `DocumentStatus`                                                                  |
| Extracción                                                          | `extraction`                                                 | Lo que devuelve la IA                                                             |
| Lector de documentos                                                | `AiExtractor`                                                |                                                                                   |
| Comercio                                                            | `merchant`                                                   | Lista del usuario, con categoría habitual (`defaultCategoryId`)                   |
| Producto de la lista                                                | `product`                                                    | Nombre y categoría. No es el `item` del ticket: los renglones apuntarán a él      |
| Texto conocido                                                      | `aliases`                                                    | Lo que un ticket imprime para un comercio o producto; dentro de cada uno          |
| Rol de categoría                                                    | `role` / `CATEGORY_ROLES`                                    | Marca la categoría que la app reconoce (`financial_charges`); no se borra         |
| Regla de categoría                                                  | `categoryRule`                                               | Comercio → categoría                                                              |
| Cuota                                                               | `installment`                                                | `number` de `total`                                                               |
| Plan de cuotas                                                      | `installmentPlan`                                            |                                                                                   |
| Período de tarjeta                                                  | `cardPeriod`                                                 |                                                                                   |
| Cierre                                                              | `closingDate`                                                |                                                                                   |
| Vencimiento                                                         | `dueDate`                                                    |                                                                                   |
| Pago mínimo                                                         | `minimumPaymentCents`                                        |                                                                                   |
| Movimiento fijo                                                     | `recurring`                                                  |                                                                                   |
| Tasa de cambio                                                      | `exchangeRate`                                               | `arsPerUsd`, `validFrom`                                                          |
| Balance del mes                                                     | `MonthSummary`                                               |                                                                                   |
| Respaldo                                                            | `backup`                                                     |                                                                                   |
| Chequeo de integridad                                               | `integrity`                                                  |                                                                                   |
| Referencia rota                                                     | `BrokenReference`                                            |                                                                                   |
| Importación / Exportación                                           | `import` / `export`                                          | Módulo `spreadsheet`                                                              |
| Vista previa                                                        | `preview`                                                    |                                                                                   |
| Duplicado                                                           | `duplicate`                                                  |                                                                                   |
| Pendientes                                                          | `pending`                                                    | Bandeja de decisiones                                                             |
| Presupuesto                                                         | `budget`                                                     | Segunda versión                                                                   |
| Migración                                                           | `migration`                                                  |                                                                                   |
| Consumo                                                             | `consumption`                                                | Qué se compró, por producto. Módulo `consumption`                                 |
| Producto (renglón de ticket)                                        | `item`                                                       | `name` texto del ticket, `product` nombre genérico                                |
| Grupo de producto                                                   | `ProductGroup`                                               | Lista fija `PRODUCT_GROUPS`                                                       |
| Unir (categorías)                                                   | `merge`                                                      | Pasa los movimientos a otra y borra la primera                                    |
| Borrar del todo                                                     | `removeForever`                                              | Solo desde la papelera                                                            |
| Volver a revisar (importación)                                      | `review`                                                     | Filas ya leídas, con cuentas o categorías reasignadas                             |
| Cerrar sesión en todos los dispositivos                             | `revokeAll` / `logout-all`                                   | Sube la versión de sesiones del usuario (`sessionVersion`)                        |
| Usuario                                                             | `user`                                                       | Quien entra a la app; sus datos son solo suyos                                    |
| Administrador                                                       | `role: admin`                                                | Crea usuarios y les cambia la contraseña; no ve datos de nadie                    |
| Desactivar (un usuario)                                             | `active: false`                                              | No puede entrar; sus datos quedan                                                 |
| Dueño (de un dato)                                                  | `userId` / `ownedByUser`                                     | El usuario al que pertenece; lo pone y lo filtra `core/db/ownerPlugin.ts`         |
| Conectar Drive                                                      | `connect` / `driveToken`                                     | El usuario le da permiso a la app para escribir en su Drive                       |
| Pago del resumen                                                    | `pay` / `cardPeriodId` / `paidCents`                         | Transferencia a la tarjeta, ligada a su resumen                                   |
| Política de privacidad / Condiciones de uso                         | `legal.privacy` / `legal.terms`                              | Páginas públicas; el texto vive en `frontend/src/shared/i18n/legal.ts`            |
| Informe por categoría                                               | `CategoryReport` / `byCategory`                              | Ingresos y egresos del mes, con el árbol de categorías                            |
| Datos iniciales                                                     | `giveStarterData`                                            | Categorías, cuentas y bancos con los que arranca cada usuario                     |
| Cambio que resulta de los montos                                    | `impliedRate`                                                | Monto ÷ monto original                                                            |
| Esperando a la IA                                                   | `retryAt` / `waits`                                          | Documento sin cupo de IA que se reintenta solo                                    |
| Banco o emisor                                                      | `institution` (`kind: bank`)                                 | Lista editable en Más → Bancos y tarjetas                                         |
| Marca de tarjeta                                                    | `institution` (`kind: network`)                              | Visa, Mastercard…                                                                 |
| Plan de cuotas                                                      | `installmentPlan`                                            | Una compra; cada cuota es un movimiento                                           |
| Devolución                                                          | `refund`                                                     | Egreso marcado que resta                                                          |
| Cargo financiero                                                    | `financialCharge` / `FINANCIAL_CHARGES_CATEGORY`             | Interés, impuesto o comisión leído de un documento                                |
| Crear las cuotas que faltan                                         | `continuePlan`                                               | Desde una cuota leída de un resumen                                               |
| Tapar (datos personales)                                            | `redactPersonalData` / `hideWords`                           | Reemplaza el dato por `***` antes de mandar el texto a la IA                      |
| Palabras para tapar siempre                                         | `hiddenWords`                                                | Las escribe el usuario; se guardan solo en su teléfono                            |
| Texto del resumen                                                   | `text`                                                       | Lo que se aprobó y se manda a la IA; se borra al confirmar                        |
| Lector de PDF                                                       | `PdfTextReader`                                              |                                                                                   |
| Copia automática en Drive                                           | `driveBackup` / `BackupStore`                                | Un archivo, `gastos-respaldo.json`, una vez por día                               |
| Lecturas con IA por día                                             | `aiDailyLimit` / `aiLimit` / `takeAiReading`                 | Límite de documentos que cada usuario manda a leer por día; `AI_LIMIT` al pasarlo |
| Informe por cuenta                                                  | `AccountReport` / `byAccount`                                | Ingresos, egresos y transferencias de cada cuenta en el mes                       |
| Meses (evolución mensual)                                           | `EvolutionReport` / `evolution`                              | Ingresos y egresos de cada uno de los últimos meses                               |
| Comercios                                                           | `MerchantReport` / `byMerchant`                              | Egresos agrupados por su descripción                                              |
| Próximos (proyección)                                               | `ProjectionReport` / `projection`                            | Este mes y los siguientes: lo cargado más lo esperado                             |
| Mostrar todo en pesos / en dólares                                  | `in` / `Consolidation`                                       | Vista consolidada; `leftOut` son los movimientos sin tasa para su día             |
| Llegó / Cambió mucho / No apareció / Todavía no llegó / En pausa    | `seen` / `changed` / `late` / `expected` / `paused`          | `RecurringState`: cómo está un fijo en un mes                                     |
| Parecen fijos (sugerencia)                                          | `RecurringSuggestion`                                        | Comercio pagado una vez por mes, 3 meses seguidos, por un monto parecido          |
| No es fijo                                                          | `ignored`                                                    | Comercio que el usuario dijo que no es fijo: no se vuelve a sugerir               |
| Comercio de un fijo                                                 | `merchantKey`                                                | Descripción normalizada con la que se reconocen sus movimientos                   |
| Resumen de cuenta                                                   | `account_statement`                                          | Movimientos de una cuenta del banco, MercadoPago o una app; `DocumentKind`        |
| Entró / salió (una transferencia leída)                             | `incoming`                                                   | Si la plata llegó a la cuenta del resumen desde otra del usuario                  |
| Saldo inicial                                                       | `openingBalance`                                             | `{ amountCents, date }`: lo que tenía al empezar ese día                          |
| Saldo (de una cuenta)                                               | `AccountBalance` / `balance`                                 | Saldo inicial más los movimientos confirmados desde ese día                       |
| Control del saldo                                                   | `BalanceCheck`                                               | En la revisión: el saldo del resumen contra el de la app                          |
| Límite diario de IA (la pieza que lo controla)                      | `aiAllowance` / `takeAiReading`                              | Se arma antes que los servicios; la cuenta del día vive en `users`                |
| Producto corregido (regla de producto)                              | `productRule`                                                | Renglón impreso → producto y grupo; se ofrece en los próximos tickets             |
| Lo que la app recuerda                                              | `remembered`                                                 | Pantalla de Más con reglas, productos corregidos y documentos confirmados         |
| Hoja Productos                                                      | `PRODUCTS_SHEET_NAME` / `productSheetRows`                   | Segunda hoja del Excel exportado; no se importa                                   |

## Cambios de términos acordados (7/11/2026, pendientes de implementar)

Hasta que se implementen, valen los términos de arriba. Cuando se haga cada cambio, se reescribe la fila que corresponda.

| Hoy                                                          | Pasará a ser                                            | Notas                                                                        |
| ------------------------------------------------------------ | ------------------------------------------------------- | ---------------------------------------------------------------------------- |
| Descripción (`description`)                                  | Se elimina                                              | Quedan el comercio (lista) y la nota                                         |
| Comercio: texto de la descripción, `merchantKey`             | Comercio, una lista: `merchant` (`merchantId`)          | Opcional; puede tener una categoría habitual (`defaultCategoryId`)           |
| Regla de categoría (`categoryRule`)                          | Se elimina                                              | La reemplaza la categoría habitual del comercio                              |
| Producto corregido (`productRule`)                           | Se elimina                                              | La reemplazan los textos conocidos del producto                              |
| Producto = renglón de un ticket (`item`)                     | **Renglón** (`item`)                                    | Con el texto impreso, el monto, la cantidad y su producto                    |
| `product`, el nombre genérico del renglón                    | Producto, una lista: `product` (`productId`)            | Cada producto apunta a una categoría                                         |
| Grupo de producto (`ProductGroup`, `PRODUCT_GROUPS`)         | Se elimina                                              | Cada uno de los 16 pasa a ser una categoría del usuario                      |
| División (`split`)                                           | Se elimina                                              | La reemplazan los renglones                                                  |
| (no existe)                                                  | Texto conocido: `merchantAlias` / `productAlias`        | Texto impreso vinculado a un comercio o a un producto                        |
| (no existe)                                                  | Rol de una categoría: `role`                            | Marca las que la app reconoce, sin buscarlas por su nombre                   |
| Cargos financieros (`FINANCIAL_CHARGES_CATEGORY`)            | Una categoría con rol, con subcategorías                | Intereses, Impuestos, Mantenimiento y comisiones                             |
| Datos iniciales (`giveStarterData`)                          | Lista nueva con subcategorías                           | Para usuarios nuevos; "Agregar categorías sugeridas" para quien ya usa la app |
| (no existe)                                                  | Estado del resumen: pagado, parcial, impago, vencido    | Se calcula, no se guarda                                                     |
