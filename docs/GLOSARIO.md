# Glosario

Cada concepto con su nombre en pantalla y en el código. Usar siempre estos términos.

| En pantalla                                                         | En el código                                                 | Notas                                                                         |
| ------------------------------------------------------------------- | ------------------------------------------------------------ | ----------------------------------------------------------------------------- |
| Movimiento                                                          | `transaction`                                                |                                                                               |
| Ingreso / Egreso / Transferencia                                    | `income` / `expense` / `transfer`                            | `TransactionType`                                                             |
| Monto                                                               | `amountCents`                                                | Entero en centavos                                                            |
| Moneda                                                              | `currency`                                                   | `ARS`, `USD`                                                                  |
| Monto original                                                      | `original`                                                   | Lo que decía un comprobante en otra moneda: `amountCents`, `currency`, `rate` |
| Fecha                                                               | `date`                                                       | Día del consumo o ingreso                                                     |
| Fecha de pago                                                       | `paymentDate`                                                | Base del balance mensual                                                      |
| Cuenta                                                              | `account`                                                    |                                                                               |
| Cuenta destino                                                      | `toAccountId`                                                | Solo transferencias                                                           |
| Monto destino                                                       | `toAmountCents`                                              | Solo entre monedas distintas                                                  |
| Efectivo / Cuenta bancaria / Billetera virtual / Tarjeta de crédito | `cash` / `bank` / `wallet` / `credit_card`                   | `AccountType`                                                                 |
| Categoría                                                           | `category`                                                   |                                                                               |
| Categoría padre                                                     | `parentId`                                                   |                                                                               |
| Nivel                                                               | `depth`                                                      | 1 a 3; se calcula, no se guarda                                               |
| Tipo de categoría                                                   | `kind`                                                       | `income` o `expense`                                                          |
| Etiqueta                                                            | `tag`                                                        |                                                                               |
| División                                                            | `split`                                                      | Parte de un movimiento con su categoría                                       |
| Ítem                                                                | `item`                                                       | Renglón de un ticket                                                          |
| Producto                                                            | `item`                                                       | En pantalla, los ítems de un ticket se llaman productos                       |
| Descripción                                                         | `description`                                                |                                                                               |
| Nota                                                                | `note`                                                       |                                                                               |
| Borrador / Confirmado / Proyectado                                  | `draft` / `confirmed` / `projected`                          | `TransactionStatus`                                                           |
| Origen                                                              | `source`                                                     | `manual`, `document`, `import`, `installment`                                 |
| Editado                                                             | `edited`                                                     |                                                                               |
| Papelera                                                            | `deletedAt`                                                  |                                                                               |
| Archivada                                                           | `archived`                                                   |                                                                               |
| Documento                                                           | `document`                                                   | Archivo subido                                                                |
| Ticket / Captura / Resumen de tarjeta                               | `receipt` / `screenshot` / `card_statement`                  | `DocumentKind`                                                                |
| Procesando / Listo / Confirmado / Descartado / Error                | `processing` / `ready` / `confirmed` / `discarded` / `error` | `DocumentStatus`                                                              |
| Extracción                                                          | `extraction`                                                 | Lo que devuelve la IA                                                         |
| Lector de documentos                                                | `AiExtractor`                                                |                                                                               |
| Comercio                                                            | `merchant`                                                   |                                                                               |
| Regla de categoría                                                  | `categoryRule`                                               | Comercio → categoría                                                          |
| Cuota                                                               | `installment`                                                | `number` de `total`                                                           |
| Plan de cuotas                                                      | `installmentPlan`                                            |                                                                               |
| Período de tarjeta                                                  | `cardPeriod`                                                 |                                                                               |
| Cierre                                                              | `closingDate`                                                |                                                                               |
| Vencimiento                                                         | `dueDate`                                                    |                                                                               |
| Pago mínimo                                                         | `minimumPaymentCents`                                        |                                                                               |
| Movimiento fijo                                                     | `recurring`                                                  |                                                                               |
| Tasa de cambio                                                      | `exchangeRate`                                               | `arsPerUsd`, `validFrom`                                                      |
| Balance del mes                                                     | `MonthSummary`                                               |                                                                               |
| Respaldo                                                            | `backup`                                                     |                                                                               |
| Chequeo de integridad                                               | `integrity`                                                  |                                                                               |
| Referencia rota                                                     | `BrokenReference`                                            |                                                                               |
| Importación / Exportación                                           | `import` / `export`                                          | Módulo `spreadsheet`                                                          |
| Vista previa                                                        | `preview`                                                    |                                                                               |
| Duplicado                                                           | `duplicate`                                                  |                                                                               |
| Pendientes                                                          | `pending`                                                    | Bandeja de decisiones                                                         |
| Presupuesto                                                         | `budget`                                                     | Segunda versión                                                               |
| Migración                                                           | `migration`                                                  |                                                                               |
| Consumo                                                             | `consumption`                                                | Qué se compró, por producto. Módulo `consumption`                             |
| Producto (renglón de ticket)                                        | `item`                                                       | `name` texto del ticket, `product` nombre genérico                            |
| Grupo de producto                                                   | `ProductGroup`                                               | Lista fija `PRODUCT_GROUPS`                                                   |
| Unir (categorías)                                                   | `merge`                                                      | Pasa los movimientos a otra y borra la primera                                |
| Borrar del todo                                                     | `removeForever`                                              | Solo desde la papelera                                                        |
| Volver a revisar (importación)                                      | `review`                                                     | Filas ya leídas, con cuentas o categorías reasignadas                         |
| Cerrar sesión en todos los dispositivos                             | `revokeAll` / `logout-all`                                   | Sube la versión de sesiones del usuario (`sessionVersion`)                    |
| Usuario                                                             | `user`                                                       | Quien entra a la app; sus datos son solo suyos                                |
| Administrador                                                       | `role: admin`                                                | Crea usuarios y les cambia la contraseña; no ve datos de nadie                |
| Desactivar (un usuario)                                             | `active: false`                                              | No puede entrar; sus datos quedan                                             |
| Dueño (de un dato)                                                  | `userId` / `ownedByUser`                                     | El usuario al que pertenece; lo pone y lo filtra `core/db/ownerPlugin.ts`     |
| Conectar Drive                                                      | `connect` / `driveToken`                                     | El usuario le da permiso a la app para escribir en su Drive                   |
| Pago del resumen                                                    | `pay` / `cardPeriodId` / `paidCents`                         | Transferencia a la tarjeta, ligada a su resumen                               |
| Informe por categoría                                               | `CategoryReport` / `byCategory`                              | Ingresos y egresos del mes, con el árbol de categorías                        |
| Datos iniciales                                                     | `giveStarterData`                                            | Categorías, cuentas y bancos con los que arranca cada usuario                 |
| Cambio que resulta de los montos                                    | `impliedRate`                                                | Monto ÷ monto original                                                        |
| Esperando a la IA                                                   | `retryAt` / `waits`                                          | Documento sin cupo de IA que se reintenta solo                                |
| Banco o emisor                                                      | `institution` (`kind: bank`)                                 | Lista editable en Más → Bancos y tarjetas                                     |
| Marca de tarjeta                                                    | `institution` (`kind: network`)                              | Visa, Mastercard…                                                             |
| Plan de cuotas                                                      | `installmentPlan`                                            | Una compra; cada cuota es un movimiento                                       |
| Devolución                                                          | `refund`                                                     | Egreso marcado que resta                                                      |
| Cargo financiero                                                    | `financialCharge` / `FINANCIAL_CHARGES_CATEGORY`             | Interés, impuesto o comisión leído de un documento                            |
| Crear las cuotas que faltan                                         | `continuePlan`                                               | Desde una cuota leída de un resumen                                           |
| Tapar (datos personales)                                            | `redactPersonalData` / `hideWords`                           | Reemplaza el dato por `***` antes de mandar el texto a la IA                  |
| Palabras para tapar siempre                                         | `hiddenWords`                                                | Las escribe el usuario; se guardan solo en su teléfono                        |
| Texto del resumen                                                   | `text`                                                       | Lo que se aprobó y se manda a la IA; se borra al confirmar                    |
| Lector de PDF                                                       | `PdfTextReader`                                              |                                                                               |
| Copia automática en Drive                                           | `driveBackup` / `BackupStore`                                | Un archivo, `gastos-respaldo.json`, una vez por día                           |
